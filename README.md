# Tic Tac Toe
Tic Tac Toe is a simple strategy game played on a 3×3 grid. Players take turns placing X and O markers, trying to get three of their markers in a row horizontally, vertically, or diagonally.

## Features
- Classic 3×3 Tic Tac Toe gameplay
- Interactive game board
- Two-player X and O gameplay
- Modern, responsive interface
- Clean and simple user experience

## Tech Stack
- HTML
- CSS
- JavaScript 

## Getting Started
1. Clone the Repository
```
git clone https://github.com/CarlyJovon/tic-tac-toe.git
```
2. Navigate to the Project
```
cd tic-tac-toe
```
3. Run the Game: Open the `index.html` file in your browser.
